# Royal Epoxi App

Sistema interno de gestão da Royal Epoxi.

## Objetivo
Gerir clientes, levantamentos, medições, materiais, orçamentos, obras, equipas, custos, caixa e rentabilidade.

## Módulos previstos
- Dashboard
- Clientes e CRM
- Visitas e medições
- Materiais e custos
- Orçamentos e PDF
- Obras e diário de obra
- Trabalhos extra e alterações
- Funcionários e permissões
- Compras e fornecedores
- Stock
- Caixa e pagamentos
- Rentabilidade por obra
- Relatórios
- Auditoria

## Fase 1
A primeira versão estabelece a arquitetura base e o modelo funcional para evoluir para uma aplicação web responsiva.
